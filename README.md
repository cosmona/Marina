# Marina

Tarjeta de felicitación web por el nacimiento de un bebé, con temática de dinosaurios: **«¡Aventura Jurásica en Casa!»**. Es una página estática con un mensaje personalizado.

## Cómo verla

Abre `index.html` en el navegador. No necesita instalar nada.

## Estructura

```
index.html
index.css
```

Hecha a partir de la misma plantilla que [monica](https://github.com/cosmona/monica).
